# Review 0002: M1.1, the store and key derivation

| | |
|---|---|
| Date | 2026-11-14 |
| Under review | The M1.1 diff without the generated `records.pb.go` and `go.sum`, with interface §5.12 and §8 |
| Reviewer | Gemini 3.8 Flash (High) through agy, about 170k tokens. Argon was cooling down |
| Triage | Claude |

Ten findings: six accepted (one as a doc note), four rejected.

| # | Finding | Severity | Triage |
|---|---------|----------|--------|
| 1 | `Get` unmarshals from bbolt's memory, so `bytes` fields would point into pages that go stale after the transaction | Critical | **Rejected, with a test.** protobuf-go copies `bytes` fields unless asked to alias (`consumeBytes` appends into a new slice, `v1.36.12`). A test reads a record, rewrites the pages 200 times and checks it is unchanged; ADR 0005 records why |
| 2 | A credential key with a zero byte, as a passkey's ID can be, makes `Key` panic | Critical | **Accepted.** Credential keys appear in store keys as their SHA-256 (`CredKey`) |
| 3 | `credential_keys` would collide for methods with one credential per user and no key | Major | **Accepted as a note.** Only methods whose keys are unique across users are indexed (ADR 0005) |
| 4 | `records.pb.go` isn't in the diff | Major | **Rejected.** It was left out of the review on purpose and is committed; CI regenerates and compares it |
| 5 | `SignKey` takes any purpose and returns the key's own slice | Major | **Accepted.** It returns copies of the signing key only |
| 6 | `Credential.key` stores a key as it travelled | Major | **Rejected.** A credential key is a public identifier (a passkey's ID, an issuer and subject), not a secret. The record's comment now says so, and that a method with a secret credential keeps only its hash |
| 7 | `Scan` passes bbolt's slices, which a caller that collects them for deletion would read stale | Major | **Accepted.** `Scan` passes copies |
| 8 | `Key()` with no parts panics | Minor | **Accepted** |
| 9 | `B` returns nil before `Init` | Minor | **Rejected.** `New` always runs `Init` first, and the package is internal |
| 10 | The rotation test ignores two errors | Minor | **Accepted** |
