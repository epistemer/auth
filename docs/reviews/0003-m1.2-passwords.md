# Review 0003: M1.2, passwords

| | |
|---|---|
| Date | 2026-11-14 |
| Under review | The M1.2 diff without the word lists and graphs, with interface §5.2, §4.6, §4.8 and §7's password tests, and ADR 0006 |
| Reviewer | Gemini 4 Argon (High) through agy, about 115k tokens |
| Triage | Claude |

Twelve findings: nine accepted (two in part), three rejected. Every
accepted finding has a test that fails without its fix.

| # | Finding | Severity | Triage |
|---|---------|----------|--------|
| 1 | Estimating only the first 100 characters can pass a weak password: a unit of 51 characters typed twice, chopped at 100, prices its second copy as random | Critical | **Accepted.** ADR 0006 claimed the cut was conservative; it isn't. A password that is a unit repeated whole is now also priced as a repeat, and the lower estimate stands. Estimating every character took up to 2.7 s at 1024, so a pattern crossing the cut inside a longer password stays a gap, recorded in ADR 0006 |
| 2 | The repeat matcher misses copies past the greedy unit's, and repeats that start inside another | Critical | **Accepted.** Both are zxcvbn's own behaviour, which the port reproduced. The unit now counts every copy, and a repeat is sought at every position; both only add matches |
| 3 | The 1024-byte limit applies before NFKC, so a 1024-byte composed password can't sign in typed decomposed, and NFKC can expand a short input 18 times | Critical | **Rejected.** §5.2.3 measures input as typed, and the refusal is an error, never a truncation, so nothing is weakened. The composed and decomposed forms are one password below the limit (§7's test). A client that types 1024 bytes in one form and sends 1025 in the other is the one case lost |
| 4 | `New` accepts parameters `decode` refuses, so its hashes never verify and `Dummy` panics; the parameter block may carry trailing text; a stored hash may ask for 4 GiB and any salt length | Major | **Accepted, the third in part.** `New` and `decode` share bounds, and amendment A4 gives the config keys the same upper bounds. The parameter block must be canonical. Salts are 8 to 64 bytes. A stored hash may still ask for up to 4 GiB: refusing a hash made with raised parameters would lock users out, and only a damaged record asks for more than the config allows |
| 5 | When a hint's word and a listed word cost the same, the covering keeps the listed one, so the error says `Common` where `Personal` is true | Major | **Accepted.** Hints are matched first, and a tie keeps the first |
| 6 | l33t substitutes every substitute in the password at once, so a hint with digits (`alice1999`) written `4lice1999` is missed | Major | **Accepted.** zxcvbn does the same. Each substitute alone is now tried too |
| 7 | Some rules have no test that fails without them: the bound in `Verify` and `Dummy`, the hints in the estimate, the blame on hints, the repeats in the whole-password check | Major | **Accepted.** Tests added. Twelve rules were each removed in turn, and a test failed every time |
| 8 | `Dummy` ignores a context that ends while it waits; a too-long password with a malformed hash hides `ErrMalformed`; the dummy's parameters differ from a stored hash's | Major | **Accepted, but not the third.** `Dummy` returns the context's error and `Verify` passes it on; `ErrMalformed` is always reported. The third reveals only that the password is over 1024 bytes, which the caller sent |
| 9 | Blame uses the longest piece rather than the characters each kind covers; a hint of short words (`Red Hat`) isn't matched joined; a hint over 1024 bytes is dropped | Major | **Accepted.** Blame sums by kind; a hint's words are also ranked joined; a long hint is cut, not dropped |
| 10 | Sequences match any code points, where zxcvbn allows only letters and digits | Minor | **Rejected.** zxcvbn's sequence matcher takes any code points; its comment says so, and it prices them as an alphabet of 26 |
| 11 | The covering omits zxcvbn's pruning of longer, costlier entries, and sorts keys in its inner loop | Minor | **Rejected.** zxcvbn has no such pruning; its `update` only returns early, as the port's does. The cost at 100 characters is 7 ms at most |
| 12 | A repeat's guesses and the covering's products can overflow to +Inf | Minor | **Accepted.** Every product is held at the largest float |
