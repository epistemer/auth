# Review 0011: M3.1, the access token

| | |
|---|---|
| Date | 2026-11-16 |
| Under review | The M3.1 diff, with interface §5.6, §5.9 and §7's bearer lines |
| Reviewer | Gemini 4 Argon (High) through agy, about 74k tokens |
| Triage | Claude |

Eight findings: seven accepted, one in part.

| # | Finding | Severity | Triage |
|---|---------|----------|--------|
| 1 | A bearer session's `Seen` was written only if its cookie token hash was unchanged, which `Refresh` will change; bearer sessions also indexed a cookie token no one has | Major | **Accepted.** The write checks the session's generation; only cookie sessions are indexed by token |
| 2 | The access token was made after the transaction committed, so a failure left a spent flow and a session no one could use | Major | **Accepted.** It is made inside the transaction |
| 3 | Tests that would pass with their rule broken: claims from the token, verified-ness from the session, idle bearer sessions, the carriers apart, nested `Load`, tokens in events and the store, key confusion | Major | **Accepted.** Each has a test |
| 4 | The claims parser took trailing data and an `app` claim of any type | Major | **Accepted.** Duplicate and case-folded keys need our key to sign them, so they change nothing |
| 5 | `iat` was never checked, and the clock was read twice | Major | **Accepted** |
| 6 | During a rotation, a token signed with the current key took one HMAC, one with the previous key two | Minor | **Accepted.** Both are always computed |
| 7 | Of two `Authorization` headers the first good one won | Minor | **Accepted.** Two sign nobody in |
| 8 | The refresh index's keys were hex to be decoded again | Minor | **Accepted in part.** The value holds the hash. `store.Scan` already copies keys, so the aliasing it worried about can't happen |

Mutation checks: each of 13 rules of the first pass and 8 of the fixes,
removed in turn, fails a test, but two equivalent: the generation check in
the write of `Seen` (it guards a race the read before it catches in
sequence), and the cookie index of a bearer session (no cookie lookup takes
a bearer session).
